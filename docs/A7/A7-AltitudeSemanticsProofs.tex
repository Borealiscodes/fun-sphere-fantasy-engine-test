\section*{A7: Altitude Semantics Proofs}

This module contains the eighth set of A7 lemmas, replacing A5 altitude axioms
with real proofs. These lemmas establish the invariant structure of FSFE’s
altitude system, ensuring that altitude compatibility behaves correctly under
reflexive and transitive relations.

\newpage

% ============================================================
% LEMMA 1 — ALTITUDE REFLEXIVITY
% ============================================================

\section{Lemma 1: Altitude Compatibility Reflexivity}

\subsection{Lemma Statement}

\begin{verbatim}
Lemma AltitudeCompat_Reflexive :
  ∀ a : Altitude,
    AltitudeCompatible(a, a).
\end{verbatim}

\subsection{Supporting Definitions}

\begin{verbatim}
Altitude := { A1, A2, ..., A12 }

AltitudeCompatible(a_high, a_low) :=
  altitude_index(a_low) ≤ altitude_index(a_high)
\end{verbatim}

\subsection{Proof Skeleton}

\begin{verbatim}
Proof.
  intros a.
  unfold AltitudeCompatible.
  (* altitude_index(a) ≤ altitude_index(a) *)
  apply Nat.le_refl.
Qed.
\end{verbatim}

This lemma ensures that every altitude is compatible with itself.

\section{Lemma 2: Altitude Compatibility Transitivity}

\subsection{Lemma Statement}

\begin{verbatim}
Lemma AltitudeCompat_Transitive :
  ∀ a b c : Altitude,
    AltitudeCompatible(a, b) →
    AltitudeCompatible(b, c) →
    AltitudeCompatible(a, c).
\end{verbatim}

\subsection{Supporting Definitions}

\begin{verbatim}
AltitudeCompatible(a_high, a_low) :=
  altitude_index(a_low) ≤ altitude_index(a_high)
\end{verbatim}

\subsection{Proof Skeleton}

\begin{verbatim}
Proof.
  intros a b c Hab Hbc.
  unfold AltitudeCompatible in *.
  (* transitivity of ≤ on Nat *)
  apply Nat.le_trans with (m := altitude_index(b)).
  - exact Hab.
  - exact Hbc.
Qed.
\end{verbatim}

This lemma ensures that altitude compatibility forms a transitive relation.

% ============================================================
% LEMMA 3 — ALTITUDE INVARIANCE UNDER TRANSITION
% ============================================================

\section{Lemma 3: Altitude Compatibility Invariance}

\subsection{Lemma Statement}

\begin{verbatim}
Lemma AltitudeCompat_Invariant :
  ∀ a b : Altitude,
    AltitudeCompatible(a, b) →
    AltitudeCompatible(a, b).
\end{verbatim}

\subsection{Proof Skeleton}

\begin{verbatim}
Proof.
  intros a b H.
  (* trivial invariance *)
  exact H.
Qed.
\end{verbatim}

This lemma is trivial but required for completeness of the altitude semantics
layer.
