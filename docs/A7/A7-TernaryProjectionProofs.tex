\section{Lemma 1: SignCollapse is Monotone}

\subsection{Lemma Statement}

\begin{verbatim}
Lemma SignCollapse_monotone :
  ∀ x y : ℝ,
    x ≤ y →
    SignCollapse(x) ≤_ternary SignCollapse(y).
\end{verbatim}

\subsection{Proof Sketch}

\begin{verbatim}
Proof.
  intros x y Hxy.
  unfold SignCollapse.
  destruct (compare x 0); destruct (compare y 0); try lia.
  all: constructor.
Qed.
\end{verbatim}

This lemma ensures that ternary collapse respects ordering.
