\section*{A7: Structural Invariant Preservation}

This module contains the first formal lemma of the A7 altitude: the preservation
of structural invariants under reversible operators. This replaces the A5 axiom
\texttt{StructuralInvariantPreserved\_axiom} with a real lemma and proof
structure.

\newpage

% ============================================================
% LEMMA STATEMENT
% ============================================================

\section{Lemma Statement}

\begin{verbatim}
Lemma StructuralInvariantPreserved :
  ∀ s : FSFEState,
    Inv_struct(s) →
    ∀ op : FSFEState → FSFEState,
      OperatorPreservesStructure(op) →
      Inv_struct(op(s)).
\end{verbatim}

The lemma states that any operator marked as structure-preserving maintains the
structural invariant of FSFEState.

\newpage

% ============================================================
% SUPPORTING DEFINITIONS
% ============================================================

\section{Supporting Definitions}

\subsection{Structural Invariant}

\begin{verbatim}
Inv_struct(s) :=
  s.sigma ≥ 0 ∧
  s.lambda ≥ 0 ∧
  QA_valid(s.qa) ∧
  Tensor_valid(s.tensor) ∧
  Branch_valid(s.branch)
\end{verbatim}

\subsection{Structure-Preserving Operator}

\begin{verbatim}
OperatorPreservesStructure(op) :=
  ∀ s : FSFEState,
    Inv_struct(s) →
    Inv_struct(op(s)).
\end{verbatim}

This definition is altitude-compatible with A6 and ensures that the lemma is
well-formed.

\newpage

% ============================================================
% PROOF STRUCTURE
% ============================================================

\section{Proof Structure}

\subsection{Proof Strategy}

The proof proceeds by:

\begin{enumerate}
  \item assuming an arbitrary FSFEState \texttt{s} satisfying \texttt{Inv_struct(s)};
  \item assuming an operator \texttt{op} satisfying \texttt{OperatorPreservesStructure(op)};
  \item applying the operator definition to show \texttt{Inv_struct(op(s))}.
\end{enumerate}

\subsection{Lean-Compatible Proof Skeleton}

\begin{verbatim}
Proof.
  intros s Hstruct op Hop.
  apply Hop.
  exact Hstruct.
Qed.
\end{verbatim}

This is the minimal Lean skeleton for the lemma. The full proof will be expanded
in A8–A12 as additional operator semantics are introduced.
