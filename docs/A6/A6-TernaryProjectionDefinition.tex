\section*{A6: Ternary Projection Definition}

This module defines the Ternary Projection operator at the A6 altitude.  
It references the full Conceptual Signal Object (CSO), which contains all
conceptual geometry collapsed into NDH-safe scalar form.  
TernaryProjection collapses only the prismatic-chromatic components of the CSO
into ternary telemetry channels.

\newpage

% ============================================================
% 1. FULL CSO REFERENCE
% ============================================================

\section{Conceptual Signal Object (CSO)}

\begin{verbatim}
CSO := {
  S_sum     : ℝ,
  O_sum     : ℝ,
  W_sum     : ℝ,

  chi_s     : ℝ,
  chi_o     : ℝ,
  chi_w     : ℝ,

  phase     : ℝ,
  braid     : ℝ,

  composite : ℝ
}
\end{verbatim}

The Ternary Projection operator uses only the prismatic-chromatic collapse
fields (S_sum, O_sum, W_sum). All other fields remain available for A7 proofs,
A8 runtime correspondence, and A9/A10 telemetry.

\section{Ternary Values}

\begin{verbatim}
Ternary := NEG | ZERO | POS
\end{verbatim}

This is the NDH-safe ternary alphabet used by the telemetry subsystem.

% ============================================================
% 3. SIGN COLLAPSE OPERATOR
% ============================================================

\section{Sign Collapse Operator}

\begin{verbatim}
SignCollapse(x : ℝ) : Ternary :=
  if x < 0 then NEG
  else if x = 0 then ZERO
  else POS.
\end{verbatim}

This operator is total, monotone, reversible-safe, and NDH-safe.

\section{Ternary Projection Operator}

\subsection{Definition}

\begin{verbatim}
TernaryProjection(c : CSO) : (Ternary × Ternary × Ternary) :=
{
  T1 := SignCollapse(c.S_sum),
  T2 := SignCollapse(c.O_sum),
  T3 := SignCollapse(c.W_sum)
}.
\end{verbatim}

Only the prismatic-chromatic collapse fields are projected.  
All other CSO fields remain untouched and available for higher-altitude
semantics (A7–A12).

\subsection{Altitude Role}

TernaryProjection is an altitude-collapsing operator:

- Domain: A6 conceptual geometry (CSO)
- Codomain: A9/A10 ternary telemetry
- Collapse: conceptual → runtime-safe

Thus it must be defined at A6 and proven at A7.
