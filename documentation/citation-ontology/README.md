🧱 Purpose of the Citation Ontology

The MAC v2.0 ontology ensures:

✔ Academic defensibility
All FSFE mathematical artifacts cite authoritative sources.

✔ Altitude‑clean citation membranes
Each class corresponds to a conceptual altitude (A1–A12).

✔ Contamination‑safe referencing
Prevents hallucinated citations and maintains provenance integrity.

✔ Modular citation architecture
Each FSFE subsystem (geometry, PDEs, reversible operators, rasa physics, etc.) has its own citation class.

✔ Zenodo‑ready structure
The ontology is designed for archival and DOI assignment.
